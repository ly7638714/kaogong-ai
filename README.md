# 🧠 行测 AI 问答助手（行测智能助教）

> 把本地名师讲义/笔记「蒸馏」成智能体方法论知识库，打包成多端可用的行测解题、智能出题、刷题与错题复盘工具。
>
> **一句话架构**：数据层资料 → 知识层(kb.js) → 应用层(01_源码/Vue3) → 分发层(网页 + 安卓 + GitHub Pages)。
>
> 本文档 = **项目开发说明**（架构 / 目录 / 模块 / 构建 / 部署 / 上传 GitHub / 安卓打包）。面向使用者的功能说明见 [`使用说明.md`](使用说明.md)。

## 一、项目定位与整体架构

个人备考自用的行测智能助教 Web 应用（Vue3 + Vite + PWA），核心闭环：
**对话解题 → 智能出题 → 刷题作答 → 存错题 → 二刷复盘 → 记忆积累 → 统计 → 导出**。

| 层 | 内容 | 状态 |
|---|---|---|
| 数据层 | `03_资料/` 本地名师讲义、真题、演示截图 | ✅ 已归置 |
| 知识层 | `01_源码/src/kb.js`（SYS 通用协议 + 10 专项模式）、积累四大库（常识/时政/成语/实词） | ✅ 已蒸馏 |
| 应用层 | `01_源码/` Vue3 + Vite5 + PWA，6 大页面 + 统一考场（出题/做题）+ 趣味功能 + 页签深链/全局异常捕获（v3.1.0） | ✅ 已完成 |
| 分发层 | `02_发布物/`（网页产物+zip）、`04_安卓/`（HBuilderX 项目）、GitHub Pages CI | ✅ 已就绪（APK 需 HBuilderX 重打包） |

**技术栈**：Vue3（Composition API）、Vite5、vite-plugin-pwa、three.js（3D）、pdfjs-dist（PDF 解析）、KaTeX、marked、ECharts（统计图）、docx、Web Speech API（朗读/语音）、File System Access API（本地文件夹保存）。

**数据存储**：全部数据在浏览器 `localStorage`（对话/错题/记忆库/设置/出题集/成绩）+ IndexedDB（文件夹句柄），无后端、不上传；可用 JSON 备份、WebDAV、本地文件夹迁移。
**🔐 本地账号（登录门，v3.7.1+）**：应用默认开启登录门，首次使用需「注册 → 登录」才能进入（`src/utils/auth.js`，用户名 + 密码 SHA-256 加盐哈希，会话存 `xc_auth`，勾「记住我」7 天免登录）。纯本地账号：无服务器、不上传、无需任何第三方服务。账号只存本机；忘记密码可在登录页「重置本地账号」重新注册，或到 设置 → 🔐 账号与安全 修改密码 / 删除账号 / 关闭登录门。**清除站点数据会丢失账号（学习数据不受影响）**。

## 三、功能清单（核心闭环 + 统一考场）

### 核心闭环
- 💬 **对话**：六大板块模式（综合/逻辑/言语/图推/资料/数量/政治/常识等）、双模型路由、流式问答（思考折叠）、选择题可点作答、变式题（举一反三）、学习诊断、图片/语音输入、朗读、**高效复盘指引**（题型判定→名师分步→正确项剖析→干扰项逐项→陷阱+秒杀→复盘）
- 🖼 **图形理解增强（可选）**：独立开源视觉模型（硅基流动/智谱/通义/Ollama 本地），发图题自动把截图复刻成 SVG 贴进回复；与主模型互不影响，免费方案可用 Ollama/LM Studio/Jan
- 📋 **错题**：二刷/三刷点选作答、掌握度、历次历史、自动「已消化」、抽认卡、今日优先、复盘（错因/秒杀/笔记）、多格式导出
- 🗂️ **积累**：常识/时政/成语/实词四大库、分类筛选、搜索、联网查词+AI学习卡+官方源直达、AI 生成 10 条扩库、艾宾浩斯复习、记忆库独立面板
- 📊 **统计**：趋势折线、板块掌握度雷达、15 周热力图、学习时长、目标分数
- 🚀 **看板**：局长欢迎词、今日任务打卡、备考倒计时、复盘率、最弱板块提示

### 统一考场（ExamPanel 出题面板，主界面「⚡单题快练 / 📝模拟组卷」入口）
- ⚡ **单题快练**：五层配置（①六大板块 → ②细分板块 → ③题型 → ④问法(选是/非/自定义) → ⑤组量 1/5/10/15/20）+ ⑥图推出题形式（一组图/两组图/九宫格/分组分类/自动轮换）。**无论对错都出「解析 + 命题人设计说明」**；「🔁 再来一题」预生成秒开；**沉浸式全屏刷题**（题干大图/选项大按钮/图推选项双列）
- 💬 **对话页可点作答（v3.7.34）**：出题意图自动渲染作答卡片（选项支持 SVG/表格）、答错「加入错题集？」确认、⛶ 全屏做题、截图题「先做一遍/直接讲解」按钮
- 📋 **仿真考试答题卡（v3.7.33+，四模块通用）**：先填涂**姓名/考场号/准考证号** + **2B 铅笔逐题填涂**（可反复改涂）→ 交卷统一判分 → 成绩单**逐题展开解析**；交卷前不泄露正确项；配置页可一键切回「答完即时看对错 + 萌宠错因分析」原体验
- 🎲 **AI 整卷出题**：内置**国考/省考真题卷面模板库**（国考副省135 / 地市130 / 执法130 / 省考联考120 / 110 / 广东90 / 浙江130 / 江苏135 / 🛠自由组卷），卷面构成可自由增删板块题量与参考时限；**出卷并发**、**进度条+预计剩余时间+可取消**、同板块题型自动轮换；支持**一拖N 分析推理**（国考一拖5/江苏一拖2）、**真假话程序真值表硬校验**；难度档（易/中/难/真题级/智能曲线）、问法（AI随机/选是/选非/自定义）、**严格质检**（唯一解/恰一正确/无逻辑谬误）
- 📂 **导入材料组卷**：上传图片/PDF/Word/txt/tex/视频截图 → AI 识别成题 → **预览校对**（可改题板块/编辑题干/删题）→ 按卷面裁剪组卷或「📌全部存入错题本」
- 📚 **错题集组卷**：从**应用内错题本**按板块自由组合组卷（可只刷未复盘、先刷错得多），做完自动判分；二刷用
- 🧠 **命题人设计说明**：每道题单窗口展示「出题意图 + 3 个干扰项陷阱设计 + 反套路/难度点 + 名师一句话破题」，看完解析仍不懂时点开
- ✨ **名师深度解析**：与对话一致的名师方法（逻辑=薛睿五步+13美丑、图推=薛睿24诀、言语=郭熙×张弓、资料=小P、常识/政治=小黑口诀），**流式逐字生成**；平面图/几何题解析会**重绘原图并标注辅助线/箭头/高亮/虚线对称轴**，立体题按**等轴测**重绘
- 🚀 **提速**：出卷参数里「出题快模型」填非思考模型（如 deepseek-chat）或勾「出题用智谱快模型」，出题/预生成/解析/质检全走快速通道；对话/深度解析仍用高质量主模型

### 图推 / 资料 / 几何 专项
- 🎨 **图形推理真 SVG**：题干真实绘制（一组图 620×140 / 两组图 / 九宫格 420×420 / 分组分类 6图），4 选项各画候选图；立体类（空间重构/截面图/三视图/立体拼合）按**等轴测**画法（立方体三面亮中暗填色、平行棱平行、遮挡虚线）
- 🔢 **组合规律**：同一题叠加 2-3 条规律（位置+数量、对称+笔画、样式+属性），真题难图推
- 📈 **资料分析**：材料形式（纯文字/表格 Markdown/混合/图形数据 ECharts 交互统计图），一篇材料配 3-5 题（第5题综合分析）
- 📐 **数量几何**：几何题题干输出 SVG 几何图（矩形/三角形/圆/组合体标注）
- 🧩 **本地真题级图推生成器**（`tutuGen.js`，零 API）：黑白块/汉字笔画/旋转/对称/叠加/分组等 20+ 规律族，确定性参数驱动 + 唯一解程序校验，SVG 自带 viewBox 零裁切，作为 AI 出题补充通道
- 🔍 **SVG 零裁切自动修复**（`svgFix.js`）：任何 AI 输出的 SVG 自动补 viewBox 并按元素内容自适应画布边界，题干/选项/聊天页/解析一处生效

### 📊 资料速算 · 四层能力训练（对话页工具栏「📊 资料速算」，本地零额度）
- **四模式 = LY《资料分析一本通》四层能力**：①判题型（14 类考点提问词秒判）→ ②找数据（文字/复杂表格/柱+折线组合图材料，时间指标单位三锁定）→ ③公式应激（KaTeX 公式选项 + 完整解题路径）→ ④速算估算（化除为乘/份数/转化系数/截位/百化分/五法则/70法则/混合居中 9 大速算）
- **速算三阶段训练**：🔍方法识别 → ✏️方法应用 → 🎯实战混合；每法配「适用条件/原理/操作步骤/口诀」教学卡
- **📚 理论课堂（第 5 页签）**：LY×小P 双师 **52 张知识点卡**（统计术语/材料阅读/公式原理/速算全技巧），搜索+四层/来源筛选+已读收藏；答题错后「📖看这张卡」联动跳转；每卡可选 AI 展开讲解（按次省 token）
- **🎲 本地确定性生成器**（`dataTrainGen.js`）：宽范围随机取数 + 唯一解校验，连续 1000 题近零重复；三档难度（入门/进阶/实战）；积分/连击/四层进度/快捷键
- **📱 全端自适应**：桌面两栏各自滚动、平板收窄、手机单列+横向卡片，滚动系统已实测 1280/800/600/390 四档视口

### 出题质量体系（v3.7.17+）
- 🧪 **本地质检 skill**（`quizVerify.js`）：严格单选·唯一正确项（4 选项互异/解析-答案一致/问法方向），不通过必重出；六大板块「质检子命题人」档案（`quizVerifyProfiles.js`）各自带本地硬规则 + 板块语义要求 + 避坑建议
- 📊 **出题历史数据反哺**（`quizLog.js`）：记录每次出题失败原因，注入提示词让 AI 越出越稳；设置·数据管理可导出/清空

### 做题与导出
- ✏️ **草稿纸 / 随手记**：全局悬浮手写球，任意页面/题目/解析处做笔记，支持透明度调节、笔粗细（0.1/0.2/0.35/0.5/0.75/1.0）、自由颜色、新建空白纸、二次查看上次记录
- 📄 **护眼纸张模式**：做题界面切「纸张」暖色护眼背景
- 📤 **导出整卷**：成绩单可导出 **Word / PDF / Markdown / LaTeX / Typst**，支持 **AI 智能排版**开关（先梳理考点/错因/秒杀规律再生成 A4 排版文档）

### 趣味与效率
- 🎵 背景音乐（内置钢琴曲 + 自定义直链 + 网易云歌单/单曲导入）
- 🐾 **养成萌宠（v3.7.24 全知升级）**：刷题攒积分喂食，🥚→🐣→🐥→🐔→🦉→🐲；内置四角色（薛神/章若楠/李星云/姬如雪）一键切换形象+克隆原声+人设，角色口吻建立在「全能行测助教」公共底座上——**萌宠通晓本项目全部功能（30 条功能百科）、六大板块名师方法论、资料速算双师 52 卡**，并感知你当前正在使用的界面；支持朗读当前内容/倍速/错题实时分析/发图问答/记忆模式
- 🗣️ **真人语音朗读系统（v3.7.24 增强）**：四引擎（智谱 GLM-TTS 超拟人默认/OpenAI 兼容 CosyVoice2/Edge 免费神经/系统语音兜底）；音色市场试音/改名/删除/自定义克隆（3-30 秒音频克隆声线）；gapless 无缝播放器「并行解码+串行调度」+ 首块 26 字 + 分块 84 字 + 预取 4 → 首句更快、块间无断流
- 💰 **AI 用量与花费实时追踪**（顶栏「💰 ¥」）：记录每次调用的模型/功能/图文/token 与花费、官方计价表、清空记录

## 五、上传到你的 GitHub

1. 在 GitHub 新建仓库（如 `kaogong-review-skill`），复制仓库地址
2. 本机执行（在项目根目录）：
   ```bash
   git remote add origin https://github.com/<你的用户名>/kaogong-review-skill.git
   git push -u origin master
   ```
3. 若用 GitHub Pages 发布网页版：另建仓库 `kaogong-ai`，把 `02_发布物/` 内容推到其 main 分支（或使用 CI 自动部署），并在仓库 Settings → Pages 开启。

> 当前环境无法直连 GitHub，推送需在你本机执行（或在网络可直连时重试）。
