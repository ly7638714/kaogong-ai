# 行测名师 AI 小助理

这是一个面向公务员行测备考的 AI 助手。它把多位行测老师的讲义和做题思路整理成可执行的方法库，再根据考生发送的题目自动识别板块和题型，按照对应的方法讲题、出题、复盘。

项目定位是个人与朋友使用的备考工具，不是通用聊天机器人。

## 主要能力

- 对话答题：文字、图片、语音都能提问，回答按题型组织
- 智能出题：单题练习、整卷练习、真题组卷、错题巩固
- 错题管理：错因归类、二刷、变式、复盘和导出
- 知识积累：常识、时政、成语、实词、记忆复习
- 学习统计：掌握度、学习时长、目标分数、复习计划
- 数据同步：支持本地备份、网页端与移动端同步

## 数据说明

所有数据默认保存在用户自己的设备本地。使用 AI 功能时，需要用户自己填写对应大模型的 API Key，项目不会代为存储或上传密钥。
