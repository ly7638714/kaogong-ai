# 视觉 Key 配置指南（2 分钟）

截图提问（图推图形 / 资料分析 / 数量关系的数字符号）必须用**视觉模型**。
推荐用智谱 **GLM-4.6V**（官方视觉推理旗舰，识别截图最准）：注册即送免费额度，够长期使用。

> ⚠️ 接口地址用 **v4** 端点：`https://open.bigmodel.cn/api/paas/v4/chat/completions`（不是 v5，v5 会 404）。

## 一、注册智谱开放平台（2 分钟）
1. 打开 https://open.bigmodel.cn （手机/电脑都行）
2. 点右上角「注册」→ 手机号验证 → 登录
3. 登录后进入「API Keys」页面（左侧菜单或 https://open.bigmodel.cn/usercenter/apikeys ）
4. 点「创建 API Key」→ 复制以 `xxxx.xxxxxxxx` 开头的 Key（形如 `a1b2c3.xxxxxxxxxxxxxxxx`）

## 二、把 Key 填进问答助手
1. 打开问答助手网址（临时网址或 Netlify 永久网址）
2. 点右上角 **⚙️ 设置**
3. **API 提供商**选：**智谱 GLM-4.6V (视觉·旗舰·推荐)**（会自动填入 v4 URL 和模型 glm-4.6v）
4. **API Key** 粘贴刚复制的 Key
5. 点「保存」→ 会显示「✅ 连接成功」

## 三、测试
- 发一张**图推截图**：AI 会直接看图形，按 6 眼法分析规律
- 发一张**资料分析/数量关系截图**：AI 会先复述数字材料再计算
- 纯文字题：也可换回 DeepSeek（更便宜，但不支持看图）

## 常见问题
- 连接失败 → ① 检查 Key 是否复制完整；② 若提示"速率限制"，等几分钟再试（智谱免费额度有每分钟请求限制）
- 显示"不支持看图" → 说明当前用的还是 DeepSeek，请到设置切到智谱
- 免费额度用完 → 智谱每天/每月有免费量，或换通义 Qwen-VL / OpenAI 的 Key


## ⚠️ 关于 GLM-4.6V（思考型视觉模型）
- 它是"思考型"模型：发送后先显示"🤔 正在思考…"（推理过程），随后给出最终答案，属正常现象
- 若接口提示"速率限制"，等几分钟再试（免费额度有每分钟请求限制）

## 📎 无法选图的浏览器怎么办？（内置/受限浏览器）
1. 点 📷 → "🔗 从图片链接添加"
2. 输入图片的公网链接 → 点"添加该图片" → 出现缩略图 → 发送
3. 把截图文件路径发给助手，助手会帮你生成公网链接；或用手机浏览器（可从相册直接选图）
