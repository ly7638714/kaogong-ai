# 在线部署指南（2 分钟上线）

把本文件夹（`deploy/`）发布到任意静态托管即可获得网址。**无需服务器**，纯前端 + 浏览器本地存储。

## 方式一：Netlify Drop（最简单，无需注册账号）
1. 打开 https://app.netlify.com/drop
2. 把本 `deploy` 文件夹**直接拖进网页**
3. 几秒后自动生成网址（如 `https://xxx.netlify.app`），可改子域名、可分享

## 方式二：GitHub Pages（推荐，长期稳定）
1. GitHub 新建仓库（如 `kaogong-ai`），把本文件夹内容上传到仓库根目录
2. 仓库 Settings → Pages → Source 选 `main` 分支 / root
3. 网址：`https://你的用户名.github.io/kaogong-ai/`

## 方式三：Vercel
1. 打开 https://vercel.com/new → 拖入本文件夹
2. 自动部署，得到 `https://xxx.vercel.app`

## 使用说明（每个用户第一次打开时）
1. 打开网址 → 点右上角 ⚙️ 设置
2. 选择提供商：**推荐「智谱 GLM-4V（视觉·免费额度）」**——注册 https://open.bigmodel.cn 获取 API Key（有免费额度）
   - 视觉模型才能真正识别：图推图形、资料分析/数量关系的数学符号数字
   - 纯文字也可用 DeepSeek（便宜），但**不支持看图**
3. 填 API Key → 保存 → 上传/粘贴题目截图即可提问
4. Key 只存在你自己浏览器的 localStorage，不会上传到服务器（本项目无后端）

## 为什么每个用户要自己的 Key？
网页是纯前端的，没有后端服务器，**不内置任何人的 Key**（安全、不会被盗用）。谁用谁在设置里填自己的 Key，互不影响。
