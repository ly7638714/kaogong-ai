# 🧠 行测 AI 问答助手

> 把名师讲义/笔记「蒸馏」成智能体方法论知识库，做成多端可用的行测解题与错题复盘工具。
> **在线使用**：https://ly7638714.github.io/kaogong-ai/ （手机/电脑浏览器直接打开，可"添加到主屏幕"获得类原生体验）

| 模块 | 说明 |
| --- | --- |
| 💬 AI 问答 | 文字题走 DeepSeek，图表/公式题走视觉模型（智谱 GLM-4.6V 等），按名师方法论讲题 |
| 🧠 十大专项模式 | 综合 / 逻辑·薛睿 / 类比·LY / 定义·LY / 言语·张弓 / 言语·三师 / 图推 / 资料数量 / 数量·秒杀 / 政治·小黑 / 常识·小黑 |
| 📚 知识库 | 薛睿五步法、图推24诀、资料四大神器、政治口诀等全量方法速查，点卡片即提问 |
| 🎯 智能训练 | 模拟出题 / 学习诊断 / 变式练习 |
| 📋 错题复盘 | 按板块/错因分类、结构化复盘模板、导出 Word/PDF/Markdown |
| 📊 统计看板 | 板块练习分布、复盘率、备考倒计时、国考冲刺节点 |
| 📚 常识·时政 | 每日积累卡片 + 自定义记忆库 + 时政时间范围推送 |
| 🗣️ 语音朗读 | 多种音色、语速/音调可调 |
| 📤 导出备份 | 对话/错题/复盘 JSON 备份与导入 |

## 🚀 快速开始

1. 打开在线网址（或本地 `npm run dev`）。
2. 点右上角 **⚙️ 设置**，填入自己的 API Key：
   - **文字模型**：推荐 DeepSeek（便宜、中文好）
   - **视觉模型**：推荐智谱 GLM-4.6V（能看图、识别公式；图推/资料表格/数学公式题需要）
3. 选择专项模式开始提问；AI 回复下可 **📌 存错题 / 🔁 出变式题 / 📄 导出复盘**。

> 🔒 Key 只保存在浏览器本地，不会上传到任何服务器，请勿把 Key 写入代码或提交到仓库。

## 🛠️ 本地开发 / 构建

```bash
npm install        # 安装依赖（pnpm 亦可）
npm run dev        # 本地开发 http://localhost:5173
npm run build      # 构建到 dist/
```

## 🌐 部署

- 本仓库已配置 GitHub Actions（`.github/workflows/pages.yml`），推送到 `main` 分支后自动构建并发布到 GitHub Pages。
- 构建产物（`dist/`）已提交在仓库根目录，Pages 直接由 `main` 分支托管。
